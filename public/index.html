SUPORTE STACKFORGE

Ferramenta gratuita para suporte e configuração do Windows, baseada no WinUtil de Chris Titus Tech.

Instalação

Abra o Windows PowerShell como administrador e execute:

irm https://stackforge.pages.dev/sup | iex

O instalador consulta a última Release oficial no GitHub e valida o pacote antes da instalação.
